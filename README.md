# 📘 ATC Knowledge Assistant

A professional Air Traffic Control knowledge management system powered by AI, designed for ATC professionals, trainers, and regulatory compliance analysts.

## ✨ Features

### Core Capabilities
- **Intelligent Q&A**: Query ATC procedures, regulations, and standards with cited sources
- **Document Drafting**: Generate SOPs, UOIs, memos, and manuals in ICAO format
- **Regulation Research**: Track current and historical regulatory changes
- **Document Comparison**: Identify discrepancies between documents with severity ratings
- **Session Memory**: Maintains conversation context for follow-up questions
- **Multi-User Support**: Secure authentication with usage tracking

### User Features
- **Chat Export**: Download conversations in Markdown or PDF format
- **Quick Actions**: One-click summarization, ICAO comparison, memo drafting
- **Personal Notes**: Save custom annotations alongside AI responses
- **Mobile Optimized**: Responsive design for controllers on the go
- **Multi-Language Support**: English, Malay, and more

### Admin Features
- **Usage Dashboard**: Monitor user activity and system metrics
- **User Management**: Add/remove users, reset passwords
- **Usage Analytics**: Track queries, response times, and popular topics
